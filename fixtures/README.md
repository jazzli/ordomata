# Fixture data

All names, dates, messages, appointments, organizations, identifiers, and
account-like values under `fixtures/` are synthetic test data. They were not
copied from an operator account, calendar, inbox, repository, billing record, or
other private source. Similarity to real people or events is coincidental.

Fixtures committed to this public repository must remain reproducible and free
of credentials, personal information, private communications, and live account
or runtime evidence.
